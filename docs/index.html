Release Notes · v1.15.0

What is New in This Release

Two major features shipped in this release — a premium mini player for the dashboard and a next-generation visualizer upgrade with AVEE-style templates — plus all the stability improvements from earlier sprints.

🎛️ Premium Mini Player NEW
  • A persistent mini player now sits at the bottom of the Home dashboard — always visible when music is playing.
  • Shows album artwork, song title, artist, and a live animated progress bar.
  • Play/pause toggle with tactile haptic feedback for a premium feel.
  • Tap the card to instantly open the full-screen player.
  • Works seamlessly for local files and streaming tracks alike.
  • Glassmorphism card with neon gradients and soft shadows matching the app theme.
🎨 Visualizer Upgrade — AVEE-Style Templates NEW
  • 4 brand-new AVEE-inspired visualizer presets: Radial Pulse, Particle Burst, Spectrum Rings, and Kaleidoscope Wave.
  • New VisualizerTemplate system lets creators add custom skins without touching core rendering code.
  • Canvas rendering is now density-aware, keeping visualizers razor-sharp on 4K and 8K displays.
  • All new templates use lightweight circle and ring primitives for buttery-smooth, battery-friendly animation.
🛠️ Stability & Lifecycle Fixes IMPROVED
  • First-launch media permission handling is now rock-solid — local library loads immediately after grant.
  • Desi Hits catalog cache timestamp is correctly updated, preventing stale data after app resume.
  • Mini player play/pause interaction now uses a shared MutableInteractionSource for consistent press-scale animation.
✨ Carried Forward from v1.14.x & v1.12.0
  • Multi-platform sync across JioSaavn, YouTube Music, Spotify, Apple Music, Deezer, and local files.
  • 10+ real-time audio visualizers with neon waveforms, particle bursts, bars, and circular scopes.
  • Built-in MP3-to-MP4 video studio for exporting shareable music videos.
  • AI assistant for natural-language music requests and mood-based curation.
  • Enlarged playback controls, smooth hang-free startup, and optimized APK size.
