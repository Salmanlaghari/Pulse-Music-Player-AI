## 🎵 Pulse Music Player AI — Features

- 📳 **Haptic Music Feedback** — Feel the beat with synchronized vibrations
- 🤖 **AI Music Assistant** — Smart AI that learns your taste and suggests songs
- 🔄 **Multi-Platform Sync** — Spotify, YouTube Music, JioSaavn, Apple Music, Deezer
- 🎨 **10+ Audio Visualizers** — AVEE-style, 3D spectrum, particle effects
- 🎛️ **AI Smart Equalizer** — Auto-tuned EQ based on genre and headphones
- 🎬 **MP3 to MP4 Converter** — Create music videos for TikTok, Reels, Shorts
- 📝 **Synced Lyrics** — Real-time karaoke-style lyrics display
- 📱 **Mini Player** — Floating music control overlay
- 🎚️ **Audio Studio** — Trim, fade, normalize, bass boost, reverb
- ⏰ **Sleep Timer** — Auto-stop with fade-out

## 🛠 Tech Stack

| Layer | Tech |
|---|---|
| Language | Kotlin 2.1 |
| UI | Jetpack Compose + Material 3 |
| Audio | AndroidX Media3 (ExoPlayer) |
| AI/ML | ML Kit + TensorFlow Lite (on-device) |
| Network | Retrofit + OkHttp |
| Database | Room |
| Build | AGP 8.7 · Gradle 8.x |

## 🚀 Quick Start

```bash

# Build APK
```
